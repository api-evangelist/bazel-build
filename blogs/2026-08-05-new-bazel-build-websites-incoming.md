We're happy to announce the launch of the new bazel.build documentation site and the new web UI for the Bazel Central Registry! New documentation site Last year, Alan Mond wrote a viral blog post that highlighted the issues with Bazel's documentation site. This led to his Let's Build the Future of Bazel Documentation birds-of-a-feather session at BazelCon 2025, where we decided to overhaul the documentation completely.
